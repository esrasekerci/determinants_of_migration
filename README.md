# Determinants of Migration
This project investigates global net migration patterns across 140 countries using panel data from the World Bank and the World Happiness Report.

## Highlights
- Dataset construction from multiple global sources (2009–2016)
- Missing data imputation with `mice`
- Random effects, marginal models, linear regression, and ML methods (REEMtree)
- Case study on Syria–Turkey migration
